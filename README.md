# SQL-Developer

## Таблици

Таблиците могат да се импортират или запазват в текстови файлове. Поддържаните типове данни са INT, DOUBLE, STRING и NULL.

## Команди за таблици

По таблиците могат да се правят промени чрез следните команди:

import <име_на_файл> <име_на_таблица> - импортира таблица от файл в паметта.

showtables - показва имената на всички таблици в паметта.

describe <име_на_таблица> - звежда имената на колоните и техните типове.

print <име_на_таблица> - извежда съдържанието на таблицата.

export <име_на_таблица> <име_на_файл> - експортира таблица от паметта в текстов файл.

select <индекс_на_колона> <стойност> <име_на_таблица> - извежда всички редове, които имат зададена стойност в дадена колона.

addcolumn <име_на_таблица> <име_на_колона> <тип_на_колона> - добавя нова колона към таблица.

update <име_на_таблица> <колона_за_търсене> <стойност_за_търсене> <дадена_колона> <нова_стойност> - променя стойностите в дадена колона на редовете, които имат зададена стойност.

delete <име_на_таблица> <колона_за_търсене> <стойност_за_търсене> - изтрива всички редове, които отговарят на условие.

insert <име_на_таблица> <стойност1> ... <стойностN> - добавя нов ред с валидирани данни в края на таблицата.

innerjoin <таблица1> <колона1> <таблица2> <колона2> - съединява две таблици по общ ключ с еднакъв тип данни и създава нова временна таблица.

rename <старо_име> <ново_име> - променя името на таблица в паметта.

count <име_на_таблица> <колона_за_търсене> <стойност_за_търсене> - преброява колко реда съдържат дадената стойност в зададената колона.

aggregate <име_на_таблица> <колона_за_търсене> <стойност_за_търсене> <целева_колона> <операция> - изпълнява операция (sum, product, minimum, maximum) над числови колони.

## Други команди

save - Записва направените промени от паметта обратно в съответните файлове на диска.

help - Извежда списък с всички поддържани команди и информация за тях.

exit - Прекратява изпълнението на програмата.
